# SERP Visual Analysis

SERP competitor analysis should be stored as text, even when the source was a screenshot.

## Capture Fields

For each observed image ad or thumbnail, record:

- keyword;
- captured_at;
- device;
- rank or visible position;
- brand;
- image type if known;
- visual subject;
- style: photo, flat illustration, 3D animation, product mockup, UI capture, icon;
- composition: close-up, centered object, lifestyle scene, split scene, banner;
- color palette;
- text overlay presence;
- repeated motifs;
- connected title/description angle;
- risk or policy notes.

## Analysis Buckets

Convert observations into:

- saturated motifs: too common to copy directly;
- table-stake visuals: expected visual language users recognize;
- whitespace scenes: useful scenes competitors underuse;
- mismatch warnings: visuals unrelated to product or too generic;
- monthly movement: newly common or fading visual concepts.

## Rules

- Do not copy a competitor composition one-to-one.
- Do not infer performance from image presence alone.
- If visual observations come from a screenshot, say so.
- If only text SERP exists, derive a visual from search intent and product scene library.
