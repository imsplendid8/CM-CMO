# Insurance Copy Guardrails

## Claims And Certainty

Do not state or imply:

- guaranteed claim payment;
- guaranteed enrollment;
- no review, no underwriting, or anyone-can-join unless verified by supplied product material;
- lowest price, best price, number one, exclusive, or absolute superiority;
- exact payout or limit unless the user supplies current source material and the output marks it for review.

Use neutral wording:

- `상품 안내에서 확인해 보세요`
- `약관에서 지급사유와 제외 조건을 함께 읽어보세요`
- `최종 보험료와 가입 조건은 공식 화면에서 확인하세요`
- `상품자료 기준 확인 필요`

## Sensitive Expressions

Mark as `검토 필요` when copy uses:

- exact time claims such as `3분`, `즉시`, `바로 가입`;
- channel claims such as `전화 없이`, `상담 없이`;
- payout amounts, maximum limits, refund claims, or savings claims;
- terms that depend on current policy wording.

## Banned Generic Patterns

Avoid these unless the user explicitly asks to preserve them:

- `갑작스러운 ... 대비`
- `든든하게 준비`
- `꼼꼼히 확인`
- `보장하세요`
- `담보를 보장`
- `필요한 순간`
- `안심하세요`
- `지금 바로`

Do not replace them with equally empty synonyms. Replace the frame with a concrete reader task.

## Safer SA Linkage

When compressing Power Content into search ad material:

- Use a decision action: `비교`, `확인`, `읽기`, `계산`, `대조`.
- Name the product and one useful angle.
- Keep description and additional description distinct.
- Additional description should add a secondary check, not repeat the main description.
- Promo copy should be a navigation cue, not a promise.
