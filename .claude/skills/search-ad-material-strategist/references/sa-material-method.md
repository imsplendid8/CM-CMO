# SA Material Method

## Strategy Axes

Create distinct material sets. Do not generate five versions of the same sentence.

- Search action: helps the searcher take the next step after the query.
- Selection criteria: explains what to compare before applying.
- Terms navigation: points to policy wording, rider names, exclusions, or conditions.
- SERP whitespace: answers a question competitors under-explain.
- Seasonal scene: only when the selected month and event dates fit.

## Material Set Fields

Each set should include:

- material_axis;
- ad title candidates;
- description candidates;
- additional description candidates;
- promotion candidate;
- sitelink candidates;
- linked Power Content topic;
- linked thumbnail concept;
- SERP basis;
- review flags;
- monthly rationale.

## Copy Principles

- Title: short, concrete, product plus one decision cue.
- Description: add a judgment point that title did not cover.
- Additional description: secondary check, not a paraphrase of description.
- Promotion: navigation cue, not a benefit promise.
- Sitelinks: information architecture, not slogans.

## Examples Of Better Frames

Prefer:

- `형사합의금 조건 읽기`
- `운전자보험 약관 항목 비교`
- `누수·풍수재 차이 보기`
- `출국 전 보상 항목 확인`
- `홀인원보다 먼저 볼 항목`

Avoid:

- `갑작스러운 사고 대비`
- `든든한 보장 준비`
- `꼼꼼하게 확인하세요`
- `지금 바로 가입`
- `보험료 최대 혜택`

## Output Discipline

Write fewer, better candidates. Every candidate should have a reason to exist. If a material cannot be tied to SERP, news, product terms, Power Content, or review draft examples, remove it.
