# 📸 캡쳐 로직 메모 (Modooflow)

> 경쟁사 가입화면을 **안전하게(개인정보 마스킹)** 수집 → 분석하는 전체 규칙을 정리한 문서입니다.
> 코드와 실제 동작 기준으로 작성. 막힐 때 이 문서부터 확인하세요.

---

## 1. 전체 작업 흐름 (순서대로)

```
①마스킹 ──▶ ②보내기 ──▶ ③검수 ──▶ ④정규단계 매핑(CSV) ──▶ ⑤검수완료 ──▶ ⑥대시보드 반영
(개인정보 가림)  (측정기록행 생성)  (회사·케이스 확인)  (공통/분기 정합)      (확정)        (플로우·분석)
```

- **①②**는 `mask-tool.html`(관리자 도구), **⑥**은 `index.html`(대시보드)
- **모두 localhost:8000** 으로 열어야 데이터가 같은 서랍에 쌓입니다 → 8번 참고

---

## 2. 파일명 규칙 (자동 인식의 핵심)

캡쳐 **파일 이름**에서 회사·가입유형·정규단계·화면명을 **자동으로 읽어** 채웁니다.

### ✅ 권장 (새 규칙) — 가장 잘 인식됨
```
회사_가입유형_정규단계번호_화면명
예) KB_신규_03_본인인증
    KB_갱신_03_본인인증      ← 번호 같음 → 자동 '공통'
    KB_갱신_05_갱신유의사항   ← 갱신만 있는 번호 → 자동 '갱신전용'
```

### 기존 규칙도 그대로 지원 (이미 작업한 70개는 안 바꿔도 됨)
```
KB_갱신_STEP1정보입력_3본인인증2(인증)
→ 회사 K사 · 갱신 · STEP1(정규단계 1) · 화면명 정보입력
```

> 핵심: **숫자(정규단계)만 신규 기준으로 맞추면** 나머지는 컴퓨터가 알아서 합니다.

### 🔁 같은 화면 버튼 변형 묶기 — `(NofM)` 표기
같은 단계인데 **버튼만 바뀌는** 캡쳐가 여러 장이면, 화면명 끝에 `(1of4)` 또는 `(1/4)` 를 붙이세요.
→ 리스팅·플로우·분기마스터에서 **한 노드로 묶여 ◀ k/N ▶** 로 넘겨봅니다.
```
KB_갱신_05_할인기준(1of4)
KB_갱신_05_할인기준(2of4)   ← 같은 '할인기준' 화면의 버튼 4상태
KB_갱신_05_할인기준(3of4)      → 1/4~4/4 한 칸으로 묶임
KB_갱신_05_할인기준(4of4)
```
(기존 캡쳐는 CSV의 `화면명` 칸에 `(1of4)`를 붙여도 동일하게 묶입니다.)

## 3. 회사 코드 매핑 (파일명 첫 토큰)

| 파일명 표기 | 대시보드 표기 |
|---|---|
| `KB` / `국민` / `K사` | **K사** |
| `삼성` / `S` / `S사` | **S사** |
| `현대` / `H` / `H사` | **H사** |
| `DB` / `D` / `D사` | **D사** |
| `당사` / `우리` | **당사** (자사) |

- 드롭다운(보내기)에는 **당사·S사·K사**만 노출(익명화).
- 매핑에 없으면 보내기 화면의 **회사 드롭다운** 값이 기본으로 쓰임.

---

## 4. 가입유형 (= 케이스)

`신규` · `갱신` · `만기도래` · `만기미도래`

- 파일명에 이 단어가 있으면 **자동 인식** (예: `KB_갱신_03_본인인증`).
- **권장 워크플로우(신규/갱신 섞여도 편함)**: 파일명에 가입유형이 없으면 보내기 드롭다운을 **`미정`(기본값)** 그대로 두고 한꺼번에 보냄 → 측정기록에 **`가입유형 미정`** 으로 쌓임 → **[📤 단계매핑 CSV 내보내기] → 엑셀에서 `가입유형` 열에 신규/갱신 일괄 입력 → [📥 가져오기]** 로 분류.
- `미정` 기록은 분류 전까지 **대시보드에 안 뜸**(검수완료해도 제외) — CSV로 신규/갱신 채우면 반영됨.

---

## 5. 정규단계 (가장 중요한 정합 키) 🔑

- **신규(최초가입)가 "정식" 순서**입니다. 신규 화면을 1, 2, 3… 으로 번호 매김.
- **공통 화면**(신규·갱신 둘 다 나오는 화면)은 **두 케이스에 같은 번호**를 줌.
- **갱신 전용 화면**은 새 번호를 줌.
- 갱신이 신규의 어떤 단계를 **건너뛰면** 그 번호는 갱신에서 비게 됨 → **생략**으로 자동 표시.

예시:
```
신규  1 차량확인   2 정보입력   3 본인인증   4 담보선택   5 결제
갱신  1 차량확인   2 정보입력   ───(3 없음)  4 담보선택   5 결제   6 갱신유의사항
                                 ⊘ 3 생략                         (갱신전용)
```

---

## 6. 분기(공통/전용/생략) 자동 판정

수기로 분기를 안 적어도, **정규단계 번호 + 가입유형**으로 컴퓨터가 판정:

| 조건 | 판정 |
|---|---|
| 같은 정규단계가 **모든 케이스**에 있음 | `공통` (회색) |
| **한 케이스에만** 있음 | `OO 전용` (주황) |
| 어떤 케이스에 **그 번호가 없음** | `⊘ 생략` |

→ 대시보드 **플로우 탭 → 플로우로 보기 → "회사 고정 → 분기 마스터"** 에서 시각화.

---

## 7. CSV 단계매핑 (수기 보정)

측정기록 〈검수·반영〉 탭 → **📤 단계매핑 CSV 내보내기 / 📥 매핑 CSV 가져오기**

| 컬럼 | 내용 |
|---|---|
| `id` | **절대 수정 금지** (기록 매칭용). 빈 id 행은 새 기록으로 추가 |
| `회사` | K사 / S사 / 당사 |
| `화면명` | 화면 상세(고유) |
| `STEP` | 단계 그룹명(예: 정보입력) |
| `가입유형` | 신규 / 갱신 / 만기도래 / 만기미도래 (옛 '케이스'와 동일) |
| `분기` | 공통 / 갱신전용 등 (비워도 자동 판정됨) |
| `정규단계` | **숫자** (신규 기준 순서) — 정렬·공통/생략 판정의 핵심 |
| `입력항목` | 쉼표 구분 |
| `평가` | 양호 / 보통 / 개선필요 |
| `메모` | 화면 설명 |

> 엑셀에서 `정규단계`만 맞춰 다시 가져오면 → 검수완료 시 분기/정렬이 반영됨.

## 8. 데이터 저장 위치 (날아가는 것처럼 보일 때) ⚠️

- 측정기록 = 브라우저 **localStorage(`cap_records`)**, 캡쳐 이미지 = **IndexedDB**.
- **데이터는 ZIP/폴더가 아니라 "여는 주소(origin)"에 묶입니다** — 대시보드 플로우 사진도 **IndexedDB에서만** 읽음(`capture_masked/`·ZIP 안 이미지는 안 읽음).
- 저장은 **여는 주소(origin)별로 분리**됩니다:
  - 실행기(`실행-윈도우.bat`/`실행-맥.command`) → `http://localhost:8000` (한 서랍 · 폴더 바뀌어도 동일)
  - 파일 더블클릭 → `file:///...폴더경로...` (**폴더마다 다른 서랍**) → 빨간 경고 배너 뜸
- 📦 **새 버전 ZIP으로 교체할 때**: 기존 폴더(zip)를 지워도 **데이터는 브라우저에 그대로** — **단, 항상 실행기(localhost:8000)로 열 때만.** `file://`로 열면 **새 폴더 = 빈 서랍**이 됩니다(데이터 사라진 듯 보임).
- 👉 **항상 실행기(localhost:8000) + 같은 브라우저**로 여세요. 더블클릭(file://) ❌
- 👉 백업 2종:
  - **버전 기록(앱 내부 자동)** = 보내기·검수완료·삭제 시 **직전 상태가 자동 스냅샷**(파일 생성 X). 실수하면 ‘버전 기록’에서 되돌리기.
  - **[💾 전체 백업(이미지 포함)]**(`_full.json`) = 기록+루브릭+**캡쳐 이미지까지**. **내가 누를 때만** 파일 저장 → **origin이 바뀌어도 완전 복원**. 버전 교체/PC 이동 전 한 번씩.
- 👉 전체 백업 파일은 **받음(Downloads) 폴더**로 떨어집니다 — **ZIP 폴더 밖**이라 폴더 지워도 안전. (복원: [📂 백업 불러오기] → 이미지 포함 백업이면 캡쳐도 복구) ⚠️ 백업을 ZIP 폴더 안에 두지 마세요.

## 9. 보안·개인정보 원칙 (반드시 준수)

- **원본 캡쳐(민감정보)는 절대 커밋 금지** — `.gitignore`로 차단. 커밋 가능한 건 마스킹 완료본뿐.
- 마스킹은 **이 브라우저 안에서만** 처리 — 이미지·개인정보 **외부 전송 0**.
- 마스킹 방식 = 검정 박스가 아니라 **가상 예시값 치환**(예: 김한화 / 820101-1\*\*\*\*\*\* / 010-1234-5678).
- AI 분석 브릿지는 **단계·항목명(익명 텍스트)만** 내보냄 — 이미지는 안 나감.
- ⚠️ **마스킹(박스·⚡자동검출) 없이 보내면 원본 이미지가 그대로 저장**됩니다(개인정보 노출). 가릴 게 있으면 반드시 가린 뒤 보내세요. (가릴 정보가 없는 화면이면 경고에서 그대로 진행 가능)
- 이미 저장된 **마스킹 안 된 캡쳐 지우기**: 측정기록 탭에서 그 기록 **[🗑 삭제]** → 이미지(IndexedDB)까지 함께 삭제됩니다.

## 10. 자주 하는 실수 체크리스트

- [ ] `file://`(더블클릭)로 열어서 데이터가 안 보임 → **실행기(localhost:8000)로 열기**
- [ ] 브라우저를 바꿔서 데이터가 안 보임 → **70개 작업한 그 브라우저로**
- [ ] 정규단계 번호를 신규 기준으로 안 맞춰서 공통/생략이 안 잡힘
- [ ] 백업을 안 해둠 → **작업 직후 [💾 전체 백업]**
- [ ] 검수 완료(✅)를 안 눌러서 대시보드에 반영 안 됨

## 11. 화면별 기능 빠른 메모

- **캡쳐 마스킹**: 드래그로 가림(예시값 치환) · **글자색·볼드 지정** · 단순클릭=화면전환 · 긁기=다중선택 · 체크박스=개별선택 · **[🗑 선택 삭제]** · 불러올 때 **이름순 자동정렬** · 사진은 창에 자동 맞춤
- **보내기**: 체크된 사진 있으면 그 N장, 없으면 현재 1장. 회사·케이스·정규단계는 파일명에서 자동
- **측정 기록 〈검수·반영〉**: 검색 + 정렬(등록순·이름·회사·정규단계·가입유형) · CSV 매핑 · 검수완료/삭제 · 버전 원복(우측 상단 🕘)
- **측정 기록 〈직접 입력·도구〉**: 현재 캡쳐 있을 때만 직접 추가 · 텍스트 일괄등록 · AI 필드추출(필드만, 평가는 추측 안 함)

## 12. 대시보드 플로우 보기 (분석 쪽)

- **플로우 탭** 상단 토글: **🖼️ 이미지 보기 / 📝 텍스트만** (캡쳐 썸네일 표시 on/off)
- **리스팅으로 보기**: 회사별 가입 단계를 가로로 — 노드는 **화면명(위) → 세로 캡쳐 → 입력수**, 정규단계 → 파일명 뒷자리 숫자 오름차순 정렬
- **변형 묶기**: `(NofM)` 표기가 붙은 같은 화면은 한 노드/칸에서 **◀ k/N ▶** 로 버튼 변화를 비교 (2번 참고)
- **플로우로 보기 → 회사 고정 → 분기 마스터**: 정규단계 기준으로 **공통/전용/⊘생략** 자동 표시
- **단계별 분석 → 단계 순서 요약**: 정규단계로 묶어 **[공통]/[전용]** 배지로 정리 (같은 단계는 1줄)
- 캡쳐 이미지가 "캡쳐 없음"으로 나오면 → 그 화면을 **마스킹→보내기**로 저장하지 않았거나 다른 origin에서 저장한 것 (8번 참고)

> ⚠️ **이 시스템의 "캡쳐 로직"은 AI 자동분할이 아니라, 파일명 규칙(회사·가입유형·정규단계·화면명) + 사람의 CSV 검수 기반입니다.** AI는 입력항목(필드) 정리에만 쓰고 등급은 추측하지 않습니다.
