============================================================
 Modooflow 실행 방법 (윈도우) — 이 파일은 메모장으로 열려요
============================================================

[가장 쉬운 방법] 폴더에서 더블클릭
  - 실행-윈도우.bat   ← 더블클릭하면 서버 켜지고 브라우저 자동으로 열림
  - (검은 창 = 서버. 작업하는 동안 켜두고, 끝나면 닫기)
  - "Windows의 PC를 보호했습니다" 뜨면 → 추가 정보 → 실행


[수동 방법] 더블클릭이 안 될 때 (파이썬 PATH 문제 등)
  1) 압축 푼 폴더(= mask-tool.html 이 보이는 폴더)를 파일 탐색기로 연다
  2) 맨 위 "주소칸" 클릭 → 글자 다 지우고 → cmd 입력 → Enter
     (그 폴더 위치에서 검은 창이 열림)
  3) 아래 한 줄을 그대로 입력하고 Enter:

        py -m http.server 8000 --bind 127.0.0.1

     ※ "py ... 인식할 수 없는" 이라고 나오면 대신 이걸로:

        python -m http.server 8000 --bind 127.0.0.1

  4) "Serving HTTP on 127.0.0.1 port 8000" 가 뜨면 성공 (검은 창은 그대로 둠)
  5) 브라우저(크롬/엣지) 주소칸에 입력 → Enter:

        http://localhost:8000/mask-tool.html      (관리자: 캡쳐·마스킹·기록)
        http://localhost:8000/index.html          (대시보드: 분석 결과)
        http://localhost:8000/monitor.html         (외부: 퍼널·뉴스)

  6) 끝나면 검은 창을 닫으면 서버 종료
     ※ --bind 127.0.0.1 = 내 PC만 접속(같은 와이파이 다른 기기 차단)


[목록이 안 뜨고 404가 나올 때]
  - 주소칸에 http://localhost:8000/  (파일명 빼고) 입력 → 폴더 목록 확인
  - 폴더 하나만 보이면 그 안으로 들어가서 mask-tool.html 클릭
    (= cmd를 mask-tool.html 이 있는 폴더에서 열어야 함)


[OCR 자동 마스킹 엔진 받기] (선택 · 인터넷 되는 곳에서 한 번만)
  - OCR엔진-받기-윈도우.bat  더블클릭  → vendor/tesseract 에 엔진 6개 받아짐
  - 그 후엔 인터넷 없이도 자동 검출(OCR) 가능
  - ※ 자동은 보조 기능. 기본은 마우스 드래그로 직접 가리기.


[손보 뉴스 실데이터 받기] (선택 · 인터넷 필요)
  - 뉴스받기-윈도우.bat  더블클릭  → newsdata.js 생성
  - monitor.html 새로고침하면 실데이터 뉴스 표시


[기본 작업 흐름]
  1) mask-tool.html : 이미지 불러오기 → 오른쪽 목록에서 선택
     → 가릴 곳 마우스로 드래그(🔍 확대 가능) → 흰 박스/예시 치환
  2) 회사 선택 후 [📨 이 화면 측정기록으로 보내기]
     (같은 화면명이면 업데이트 + 이전 버전 보관)
  3) [측정 기록] 탭 : 작업 시기(회차)별로 묶임
     → 체크한 것만 [✅ 선택 검수 완료]로 대시보드 반영 (예시·테스트는 체크 해제/삭제)
  4) index.html 대시보드에서 결과 확인 (고객친화 용어표현 탭 하단에 마스킹본 썸네일도 표시)

  ※ 변경 사항을 화면에 반영하려면: 브라우저에서 Ctrl + Shift + R (강력 새로고침)
  ※ 백업: 측정 기록의 [💾 전체 백업]으로 modooflow_backup.json 저장 → [📂 불러오기]로 복원
