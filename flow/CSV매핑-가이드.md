# 단계매핑 CSV — 작성 가이드

측정 기록의 **가입유형·정규단계·입력항목·평가**를 엑셀에서 한 번에 채워 넣는 양식입니다.
`측정 기록` 탭 → **[📤 단계매핑 CSV 내보내기]** 로 받고, 채운 뒤 **[📥 가져오기]** 하면 `id`로 매칭돼 반영됩니다.

> ❓ **내가 다 해야 하나요?** — 아니요.
> 파일명 규칙(`회사_가입유형_STEP번호_화면명`)을 지켜 보냈으면 **회사·가입유형·정규단계가 자동**으로 들어가 있습니다.
> CSV는 **자동으로 안 채워진 것만 보완**하는 용도예요. (특히 가입유형 '미정', 정규단계 빈칸, 입력항목)
> 또한 **검수완료한 기록은 가입유형이 '미정'이어도 대시보드에 '신규'로 일단 표시**됩니다 — 안 보여서 막히는 일은 없어요.

---

## 열(column) 설명

| 열 | 뜻 | 누가 채우나 | 비고 |
|---|---|---|---|
| **id** | 기록 매칭 키 | ❌ 건드리지 마세요 | 이 값으로 기존 기록을 찾아 갱신. **빈 id 행은 새 기록으로 추가** |
| **회사** | 당사 / S사 / H사 / D사 / K사 | 보통 자동 | 파일명 앞 회사명에서 자동 인식 |
| **화면명** | 캡쳐 화면 이름 | 자동(파일명) | 대시보드에 표시되는 이름 |
| **세부단계** | STEP 뒤 2번째 이름(예: 가입설계동의) | 자동(파일명)·선택 | 플로우에 `화면명 › 세부단계`로 병합 표시 |
| **STEP** | 그 회사가 화면에 쓴 단계 표기(예: STEP4) | 선택 | 표시·참고용 |
| **가입유형** ⭐ | **신규 / 갱신** (2종만) | **여기서 채움** | **대시보드가 신규/갱신 플로우로 묶는 기준.** 비우면 신규로 기본. 목록 밖 값은 무시 |
| **분기** ⭐ | 고객타입 — 신규: **신규·타사만기도래·타사만기미도래** / 갱신: **갱신** | 보통 자동·여기서 보완 | **신규 플로우 안에서 이 값으로 갈라짐.** (가입유형=신규일 때만 의미) |
| **정규단계** ⭐ | 회사 공통 단계 **번호**(1,2,3…) | **여기서 채움** | 같은 의미 단계에 같은 번호 → 회사끼리 나란히 정렬·비교 |
| **입력항목** | 쉼표로 구분한 입력 필드명 | 여기서 채움 | 예: `이름,생년월일,면허번호` → 개수가 ‘입력수’ |
| **버튼수** | 화면 하단 버튼 개수(다음 등) | 선택 | 직접 입력(이미지 자동검출 X) |
| **업셀제안담보** | 업셀 팝업이 제안하는 담보 | 선택 | 업셀 노드/표에 표시 |
| **보험료** | 캡쳐에서 확인한 보험료 | 선택 | 업셀 노드/표에 표시 |
| **평가** | 양호 / 보통 / 개선필요 | 선택 | 단계별 평가 색상 |
| **메모** | 자유 메모 | 선택 | 화면 설명·특이사항 |

⭐ = 비교/플로우 정확도에 가장 중요 (가입유형·분기·정규단계).

> **가입유형 vs 분기** — 가입유형은 **신규/갱신**(큰 플로우), 분기는 신규 안에서 **고객타입**(신규·타사만기도래·타사만기미도래). 갱신/만기 분류는 반드시 **가입유형(갱신)** 또는 **분기(타사만기…)** 로 정확히.

---

## 정규단계가 핵심 — 예시

회사마다 순서·이름이 달라도 **같은 의미의 단계에 같은 번호**를 주면, 대시보드가 회사들을 같은 줄에 정렬해 비교합니다.

| id | 회사 | 화면명 | 가입유형 | 정규단계 | 입력항목 | 평가 |
|---|---|---|---|---|---|---|
| rs101 | K사 | 본인인증 | 신규 | **3** | 휴대폰인증 | 보통 |
| rs102 | S사 | 본인확인 | 신규 | **3** | 휴대폰인증 | 양호 |
| rs103 | K사 | 차량선택 | 신규 | **2** | 차량번호,차명 | 양호 |

→ K사 ‘본인인증’과 S사 ‘본인확인’이 **둘 다 정규단계 3** 이라 같은 단계로 묶여 비교됩니다.

## 작성 순서

1. `측정 기록` 탭 → **[📤 단계매핑 CSV 내보내기]**
2. 엑셀(또는 구글시트)로 열기 — **`id` 열은 수정 금지**
3. 빈 칸 채우기 → **가입유형**(신규/갱신/만기), **정규단계**(번호), 필요하면 **입력항목·평가**
4. **CSV(UTF-8)로 저장**
5. `측정 기록` 탭 → **[📥 가져오기]** → `id`로 매칭돼 자동 반영
6. `측정 기록`에서 체크 → **[✅ 선택 검수 완료]** → 대시보드(플로우)에 반영

## 자주 하는 실수
- **분기만 채우고 가입유형을 비움** → 신규/갱신으로 안 갈라짐. **갱신/만기는 반드시 ‘가입유형’ 열**에 넣으세요.
- **id를 지우거나 바꿈** → 기존 기록과 매칭 실패(새 기록으로 추가됨). 손대지 마세요.
- **엑셀에서 ‘일반’ 저장(xlsx)** → 반드시 **CSV UTF-8**로 저장해야 가져오기가 됩니다.
