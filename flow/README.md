# Modooflow — 자동차보험 가입 플로우 인텔리전스

경쟁사 가입 플로우 분석 · 용어 진단 · 개선/AB · 퍼널/뉴스 리포트를 한 곳에서.

## 내부용 / 외부용 구성

내부용·외부용 두 가지 산출물로 구성됩니다.

| | 내부용 (업무용) | 외부용 (공유용) |
|---|---|---|
| 파일 | `index.html` (전체) | `external.html` (별도) |
| 내용 | 경쟁사 캡쳐·분석·벤치마크·마스킹 등 전부 | **구글 퍼널 리포트 + 뉴스 리포트만** |
| 데이터 | `data.js`(경쟁사 분석) 포함 | 경쟁사 데이터 **물리적으로 없음** |
| 실행 | 로컬 PC(file://) 또는 사내망 | 외부 호스팅/공유 가능 |

> 외부 공유에는 `external.html`을 사용하세요. (`index.html`은 경쟁사 분석 데이터를 포함하는 내부용입니다.)

### 외부 배포 시 함께 올리는 파일
- `external.html`, `styles.css`, (선택) `newsdata.js`
- ❌ `index.html`, `data.js`, `app.js`, `capture_masked/` 는 올리지 않음

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` · `styles.css` · `app.js` · `data.js` | 내부 대시보드 (구조/디자인/로직/데이터) |
| `external.html` | 외부 공유용 (퍼널+뉴스 리포트만) |
| `mask-tool.html` | 마스킹 도구 — ⚡자동 검출(브라우저 OCR)+수동 보완 · 이미지는 로컬에서만 처리 |
| `masker.py` | 대량 자동 마스킹(OCR) — `pip install -r requirements-masker.txt` |
| `make_manifest.py` | 마스킹 캡쳐 → 대시보드 목록(`capture_masked/captures.js`) |
| `news_watch.py` | 뉴스 감지 + 카카오 알림 → `newsdata.js` |

## 캡쳐 분석 흐름 (내부)
1. 가입화면 캡쳐 → `mask-tool.html` 또는 `masker.py`로 **예시치환 마스킹**(개인정보는 로컬에서 가상값 치환)
2. 마스킹본을 `capture_masked/`에 두고 `python3 make_manifest.py`
3. 대시보드 **용어 → 캡쳐별 보기**에서 확인 · `DATA/STEP/TERM`에 실제 분석값 입력

원본 캡쳐(`capture/`)는 `.gitignore`로 커밋 차단됩니다. **마스킹본만** 사용하세요.

## AI 분석 — C(하이브리드) 방식
민감정보는 로컬에서 마스킹하고, **마스킹본(개인정보 0)만** 외부 AI(Claude)에게 보내 분석합니다. 분석 결과는 `측정 기록` 탭에서 검수자가 확정합니다.

**흐름**
1. (로컬) 캡쳐 → `mask-tool.html`/`masker.py`로 **예시치환 마스킹**
2. 마스킹본을 `capture_masked/`에 넣고 커밋·푸시 (마스킹본이라 안전)
3. (AI) Claude가 마스킹 캡쳐를 분석해 **초안 JSON** 생성 → `ai_draft.json`
4. (검수) `측정 기록` 탭 → **AI 초안 불러오기(JSON)** → 각 항목 검수중→확정

**초안 JSON 형식** (한 화면 = 한 객체)
```json
[
 {"co":"당사","screen":"담보선택","step":"STEP4",
  "prefill":"부분","auto":"N","grade":"bad",
  "fields":"대인, 대물, 자손, 무보험, 자차, 특약12개",
  "memo":"특약 과다 · 용어 미설명"}
]
```
- `prefill`: Y / 부분 / N · `auto`(자동조회): Y / N · `grade`: good / mid / bad
- 불러오면 전부 **'AI 초안'** 상태 → 검수자가 확인 후 확정

> 지금 바로 테스트: `ai_draft_sample.json`을 측정 기록 탭에서 불러와 보세요.

## 관리자 도구 → 대시보드 연계

### 실데이터 모드 (`LIVE_MODE`)
`data.js`의 `const LIVE_MODE` 한 줄로 동작 모드를 정합니다(앱 로직 `app.js`는 공통).

- `true` (**local-only** 브랜치): 샘플 경쟁사 수치를 쓰지 않고, **내가 직접 캡쳐해 확인·기록한 측정 데이터만으로** 플로우·단계별 분석·벤치마크·루브릭을 채웁니다. 기록이 없으면 "캡쳐를 불러오세요" 빈 상태로 표시됩니다.
- `false` (**main**): `data.js`의 샘플 데이터로 데모(목업) 표시 — 예시 제출용 백업.

캡쳐 이미지는 외부(AI 포함)로 전송하지 않고 브라우저 안에서만 처리하며, 저장소(`localStorage`)와 화면에만 반영됩니다.

### 확인·기록 → 대시보드 연계
`mask-tool.html`에서 마스킹한 화면을 보고 **측정 기록 → 확인·기록 추가**를 누르면, 같은 브라우저의 저장소(`cap_records`/`cap_rubric`)를 통해 `index.html` 대시보드에 자동 연계됩니다.

- **🤖 AI 분석 브릿지 (온라인은 이 단계만)**: 로컬에서 추출·확인한 기록을 **익명 텍스트 + 프롬프트**로 내보내(📤) Claude에 붙여넣고, 받은 JSON을 다시 넣으면(📥) 평가·prefill·메모가 채워집니다. **이미지·개인정보는 전송하지 않고 단계·항목명만** 오갑니다(거버넌스: 이미지/PII=로컬, 익명 텍스트=온라인 분석 가능).
- **⌨️ 텍스트로 빠르게 입력**: 캡쳐 없이 `회사[/케이스]: 단계1, 단계2(항목·항목), …` 형식으로 플로우만 정리해 일괄 등록.
- **📷 현재 캡쳐에서 입력 항목 자동 추출**: [마스킹] 탭에 불러온 화면을 브라우저 OCR로 읽어 입력 항목 후보를 폼에 채웁니다(추정값 → 직접 수정·확인 후 기록). 이미지를 불러오면 자동 마스킹도 함께 실행됩니다.
- **플로우·단계별 분석·벤치마크**(실데이터 모드): 기록의 회사·케이스·화면·입력 항목으로 `DATA`/`STEP`을 재구성

- **개선진단**(벤치마크·개선 → 개선방안): `cap_records`의 회사·단계·평가·메모를 반영
- **루브릭 채점표**: 확인·기록한 필드를 점수로 자동 환산
  - 입력 효율 = 입력 항목 수(적을수록 ↑) · prefill·자동조회 = prefill/자동조회 값 · 용어/인증/약관 = 평가등급(양호/보통/개선필요) 환산
  - 루브릭 탭에서 **수기 채점**하면 자동연계보다 우선합니다.
- 두 HTML을 각각 다른 탭에서 열어두면 한쪽 저장이 다른 쪽에 즉시 반영됩니다(`storage` 이벤트).

## 손보 뉴스 실데이터

`monitor.html`의 손보 뉴스는 **공개 뉴스(Google News)** 기반 실데이터로 채울 수 있어요.

- **`뉴스받기-윈도우.bat`**(맥은 `뉴스받기-맥.command`)를 더블클릭하면 `news_watch.py --dry-run`이 실행돼 손해보험 가입/개편 기사를 모아 **`newsdata.js`**를 생성합니다(카카오 설정 불필요·인터넷 필요).
- 생성된 `newsdata.js`가 `monitor.html` 옆에 있으면 자동으로 실데이터가 표시되고, 없으면 예시(샘플)로 보입니다.
- 키워드·회사 필터는 `news_watch.py`의 `KEYWORDS`/`COMPANIES`에서 조정. 카카오 '나에게' 알림까지 쓰려면 토큰 설정 후 `python3 news_watch.py`(‑‑dry‑run 없이) 실행.

## 오프라인(인터넷 차단) 실행

`index.html`과 `mask-tool.html`은 **파이썬·서버·인터넷 없이** 브라우저로 파일을 더블클릭(`file://`)만 하면 동작합니다.

- 모든 스크립트/스타일/폰트가 로컬 파일이고 실행 중 외부 통신이 없습니다(대시보드는 외부 요청 0).
- 데이터는 `data.js`에 내장(전부 샘플·가상값), 기록은 브라우저 `localStorage`에 저장됩니다.
- 단, `mask-tool.html`의 **⚡자동 검출(OCR)** 만은 엔진 파일이 필요합니다.
  - **`OCR엔진-받기-윈도우.bat`**(맥은 `OCR엔진-받기-맥.command`)를 인터넷 되는 곳에서 한 번만 더블클릭하면 `vendor/tesseract/`에 엔진(약 15~20MB)이 받아져 **완전 오프라인 OCR** 가능
  - 엔진이 없거나 `file://` Web Worker가 막힌 브라우저(Chrome)에서는 자동 검출만 안내 후 비활성 — **드래그로 직접 가리는 기본 흐름은 그대로 동작**합니다(Firefox에서는 `file://`로도 OCR 가능).
