캡쳐 마스킹 도구

가릴 곳을 마우스로 드래그하면 그 자리에 예시값(김한화 등)이 덮여 가려집니다(흰 박스·모자이크도 선택 가능). 큰 이미지는 🔍 확대 후 드래그하세요. [⚡ 자동 검출(OCR)]은 보조 기능(엔진 있을 때만). 잘 안 되면 직접 드래그로 가리면 됩니다. 처음이면 좌측 ❓ 도움말 참고.
마스킹은 이 브라우저에서만 처리됩니다(이미지·개인정보 외부 전송 없음). 마스킹 후 [측정 기록]에서 화면을 기록하면 대시보드에 자동 반영됩니다.
⚠️ 처리할 항목: 주민등록번호·운전면허번호·차량번호·연락처·주소·이름·생년월일·보험료/계약번호 등. 예시 치환 모드는 실제 값 위에 가짜 예시값(예: 김한화)을 그려 화면을 자연스럽게 유지합니다. 저장 후 결과 이미지를 다시 확인하세요. (직접 칠하는 방식 = 누락 방지)
치환 예시: 이름 주민번호 주소 전화 생년월일 차량번호 면허번호 이메일
가릴 곳을 마우스로 드래그하면 예시값으로 가려집니다(🔍 확대 가능). 되돌리기로 취소.
불러온 이미지가 없습니다. 위 버튼으로 캡쳐를 선택하세요. (여러 장 가능)
회사 가입유형 파일명에 신규/갱신 있으면 자동 · 없으면 '미정'으로 보내고 측정기록 CSV에서 일괄 분류
사진 목록 체크/긁기로 여러 장 선택 → 아래 [측정기록으로 보내기]

측정 기록 · 화면 설명

[마스킹] 탭에서 [📨 측정기록으로 보내기]로 보낸 화면이 여기 검수 대기로 쌓입니다(작업 시기별). 회사·케이스·평가를 확인·수정하고 📥 CSV로 정규단계·분기를 매핑한 뒤, 체크 → [✅ 선택 검수 완료]를 누르면 대시보드(개선진단·루브릭)에 반영됩니다.
🗂️ 단계 매핑 (회사 간 비교 정확도↑)
화면명을 엑셀로 받아 정규단계(회사 공통 단계명·예: 차량확인/담보선택)·분기(최초신규/만기도래/공통 등)·케이스를 채워 다시 가져오면, 회사 간 같은 단계가 정렬돼 플로우·비교가 정확해집니다. id 열은 수정하지 마세요(기록 매칭용). 빈 id 행은 새 기록으로 추가됩니다.
[마스킹] 탭에 불러온 화면을 브라우저에서 읽어 채웁니다(외부 전송 없음)
🤖 AI 분석 브릿지 (온라인은 이 단계만)
입력 항목(필드) 정리 전용 — 기록을 익명 텍스트로 내보내 Claude/ChatGPT에 붙여넣고, 받은 JSON을 다시 넣으면 필드만 깔끔하게 정리됩니다. 등급·평가는 추측하지 않습니다(부정확 방지) — 평가·판단은 검수·반영 탭의 📥 매핑 CSV 가져오기로 사람이 입력합니다. 이미지·개인정보는 전송되지 않습니다(단계·항목명만).

루브릭 채점

화면 설명을 점수로 환산하는 기준표. 회사를 골라 항목별로 수기 채점해 저장합니다. (총 100점)

❓ 도움말 — 처음이세요? 이대로만 따라하세요

개인정보가 들어간 캡쳐를 이 브라우저 안에서만 가린 뒤(외부 전송 0), 분석 대시보드로 보내는 도구예요. 순서대로만 하면 됩니다.
1단계 · 캡쳐 마스킹 (개인정보 가리기)
  1. 이미지 불러오기로 캡쳐를 선택해요(여러 장 가능). → 오른쪽 목록에 쌓여요.
  2. 오른쪽 목록에서 사진을 클릭하면 왼쪽 큰 화면에 떠요. 크면 🔍+로 확대.
  3. 가릴 곳(이름·주민번호·차량번호·전화 등)을 마우스로 드래그하면 그 자리에 예시값(김한화 등)이 덮여요.
  4. 잘못 가렸으면 되돌리기, 다 지우려면 이 이미지 초기화.
  5. 모드: 예시 치환(기본) / 흰 박스 / 모자이크 중 선택. (⚡ 자동 검출 OCR은 엔진 있을 때만 동작하는 보조기능 — 안 되면 그냥 드래그하세요.)
2단계 · 측정기록으로 보내기
  1. 가리기가 끝난 화면에서 회사를 고르고 [📨 이 화면 측정기록으로 보내기].
  2. 같은 회사+화면명으로 또 보내면 업데이트돼요(이전 상태는 버전 기록에 보관).
  3. 검수 완료한 마스킹본은 대시보드 고객친화 용어표현 탭 하단 ‘마스킹 캡쳐’에 썸네일로 자동 표시돼요.
3단계 · 측정 기록에서 검수 → 대시보드 반영
  1. 측정 기록 탭에 가면 보낸 화면이 작업 시기(회차)별로 묶여 있어요.
  2. 전체 선택 / 시기별 / 개별 체크로 반영할 것만 고르고 [✅ 선택 검수 완료] → 대시보드 반영.
  3. 예시·테스트는 체크 해제하거나 [🗑 선택 삭제]. 반영된 걸 되돌리려면 [↩ 선택 반영 취소].
  4. 실수했을 땐 [🕘 버전 기록]에서 작업 시점을 골라 원복할 수 있어요.
  5. 안전 보관: [💾 전체 백업]으로 파일 저장 → [📂 백업 불러오기]로 복원.
📊 단계 매핑 (회사 간 비교 정확도↑) — 쓰는 법
  1. 측정 기록 탭에서 [📤 단계매핑 CSV 내보내기] → 엑셀로 열기. id 열은 수정 금지(기록 매칭용).
  2. 빈 칸을 채워요 — 특히 가입유형(신규/갱신)과 정규단계(회사 공통 단계 번호: 같은 의미 단계에 같은 번호 → 회사끼리 나란히 비교).
  3. 그 외 분기(고객타입: 신규·타사만기도래·타사만기미도래) · 세부단계(2번째 이름) · 버튼수 · 업셀제안담보·보험료도 적을 수 있어요.
  4. CSV(UTF-8)로 저장 → [📥 매핑 CSV 가져오기] → id로 매칭돼 표/플로우에 반영.
  5. 파일명에 신규/갱신/만기·STEP번호가 있으면 자동 분류돼요. (자세한 설명: 동봉 CSV매핑-가이드.md)
⚠️ 분기 ≠ 가입유형 — 갱신/만기 분류는 반드시 가입유형 열로! (분기만 채우면 신규/갱신으로 안 갈라져요)
4단계 · 결과 보기 & AI 분석(선택)
  • 대시보드(index.html)에서 플로우·단계별·벤치마크·용어 확인(용어 탭 하단에 마스킹 캡쳐 썸네일). (변경 안 보이면 Ctrl+Shift+R)
  • AI 분석: 측정기록의 [📤 AI 분석용 텍스트 복사] → Claude에 붙여넣기 → 받은 JSON을 [📥 AI 결과 적용]. 이미지·개인정보는 안 나가고 단계·항목명(익명)만 갑니다.
⚠️ 모든 처리는 이 브라우저(로컬) 에서만 이뤄집니다. 캡쳐 이미지는 외부로 전송되지 않아요. 같은 주소(localhost)로 열어야 마스킹 도구↔대시보드가 데이터를 공유합니다.
