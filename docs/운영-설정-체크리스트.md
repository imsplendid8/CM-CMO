# 운영 설정 체크리스트

_최종 갱신: 2026-10-08_

자동화가 돌아가려면 **세 곳**에 설정이 있어야 한다. 값은 이 문서·저장소·채팅 어디에도 적지 않는다(이름만).
설정이 빠지면 6시간마다 도는 **대시보드·도구 헬스 체크**의 `worker-config` 작업이 이슈 1건 + 텔레그램 1회로 알리고, 해결되면 이슈를 자동으로 닫는다.

## 1. Cloudflare 워커 `modooflow-naver-proxy`
위치: dash.cloudflare.com → Workers & Pages → `modooflow-naver-proxy` → **Settings**

| 구분 | 이름 | 용도 | 없으면 |
|---|---|---|---|
| Bindings → KV namespace | `USAGE` | 사용량·레이트리밋·정시 호출 기록 | 검색·검색량 조회 전부 503 |
| Secret | `NAVER_ID`, `NAVER_SECRET` | 네이버 뉴스·검색·데이터랩 | 실시간 검색 500 |
| Secret | `AD_KEY`, `AD_SECRET`, `AD_CUSTOMER` | 검색광고 검색량 | 검색량 조회 500 |
| Secret | `GH_DISPATCH_TOKEN` | 정시 발송(06:30·07:20·07:45·08:00·08:30·13:20·13:45·14:00 KST) | GitHub 예비 실행으로 1~3시간 늦게 발송, 브리프 맨 위에 경고 |
| Trigger Events → Cron | `*/5 * * * *` | 정시 스케줄러(1개만 — 무료 요금제 5개 제한) | 정시 발송 안 됨 |
| (선택) Secret | `ANTHROPIC_API_KEY`, 변수 `DASHBOARD_AI_ENABLED` | 대시보드 AI(기본 꺼짐) | — |
| (선택) D1 `FEEDBACK_DB`, Secret `ACTOR_HASH_SALT` | 비공개 검수 피드백 | 피드백 저장 503 |
| (선택) KV `GSC_TOKENS`, Secret `GOOGLE_OAUTH_*` | Search Console 연동 | GSC 화면 비활성 |

- 새 값은 **+ Add** 버튼으로 추가한다. 표의 연필(✏️)은 기존 항목 수정 창이다.
- 휴대폰에서는 Deploy 버튼이 키보드에 가려진다 — 키보드를 닫고 창을 끝까지 내리거나 PC에서 한다.
- 점검: `https://modooflow-naver-proxy.angle0102.workers.dev/health` → `missing`이 빈 목록이면 정상(값은 표시되지 않음).
- **워커 코드 배포는 자동**: GitHub Secrets에 `CLOUDFLARE_API_TOKEN`(Cloudflare → My Profile → API Tokens → Create Token → 템플릿 **Edit Cloudflare Workers**)과 `CLOUDFLARE_ACCOUNT_ID`(Workers & Pages 화면 오른쪽 Account ID)를 넣으면, `proxy/`가 main에 바뀔 때마다 `Deploy Cloudflare Worker` 워크플로가 배포한다. Cron(`*/5`)도 함께 적용되고, 대시보드의 KV(USAGE·GSC_TOKENS)는 이름으로 찾아 이어 붙이며, 워커 Secret은 그대로 유지된다. 수동 재배포: Actions → Deploy Cloudflare Worker → Run workflow.
- 자동 배포를 쓰지 않을 때만 Edit code에 붙여 넣는다. 편집기는 화면에 보이는 줄만 그리므로 휴대폰 '전체 선택'은 약 100줄만 잡힌다 — PC에서 코드 영역 클릭 후 Ctrl+A.

### GH_DISPATCH_TOKEN 발급·갱신
github.com/settings/personal-access-tokens/new → Only select repositories: `CM-CMO` → Permissions: **Actions = Read and write** → Generate.
만료되면 정시 호출이 401로 실패하고 헬스 체크가 "토큰 만료 가능"으로 알린다 — 같은 방법으로 새로 만들어 워커 Secret을 Rotate.

## 2. GitHub Actions Secrets
위치: github.com/imsplendid8/CM-CMO → Settings → Secrets and variables → Actions

| 이름 | 쓰는 워크플로 |
|---|---|
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | news-clip · signals · trends · daily-brief · fire-watch |
| `NAVER_AD_API_KEY`, `NAVER_AD_SECRET`, `NAVER_AD_CUSTOMER` | searchad |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_IDS`(또는 `TELEGRAM_CHAT_ID`) | daily-brief · fire-watch · health-check |
| `FIRE_TELEGRAM_CHAT_IDS` | fire-watch |
| `SMTP_USER`, `SMTP_PASS`, `EMAIL_TO` (선택 `SMTP_HOST`, `SMTP_PORT`, `EMAIL_FROM`) | daily-email |
| `DATA_GO_KR_KEY` | signals(기상특보) |
| `MOJ_EXIT_API_KEY`, `TOUR_API_*` | signals(출국·관광 통계) |
| `CAR_NEWREG_API_URL`, `CAR_NEWREG_KEY`, `CAR_NEWREG_FORM_ID`, `CAR_NEWREG_STYLE_NUM` (선택 `CAR_NEWREG_EXTRA_PARAMS`) | signals(자동차 등록대수) |
| `GSC_CLIENT_ID`, `GSC_CLIENT_SECRET`, `GSC_REFRESH_TOKEN`, `GSC_SITE_URL` | content-intelligence |
| `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` | worker-deploy(워커 자동 배포) |
| `OPENAI_API_KEY` | generate-image-assets(썸네일 PNG 생성 · 유료) |

**썸네일 자동 생성**: 권장은 구독(OAuth)으로 내 PC에서 매일 자동 실행 — `docs/ima2-oauth-image-generation.md`의 '자동 실행'(`scripts/register_image_autogen.ps1` 한 번 실행). 아래 유료 API 경로는 선택 사항.

**(선택·유료) GitHub 월간 자동 생성**: Settings → Secrets and variables → Actions → **Variables** 탭에 `IMAGE_AUTOGEN_LIMIT`(1~20)을 만들면
매월 1일 11:00 KST에 월간 썸네일 계획(09:30)의 대기 항목을 그 수만큼 실제 PNG로 생성·검증·커밋한다. 변수가 없거나 0이면 미리보기만(비용 0).
`OPENAI_API_KEY`가 없으면 API를 부르지 않고 실패로 기록한다.

GitHub Secrets는 워크플로 전용이다. **워커는 읽지 못한다** — 같은 키라도 1번에 따로 넣어야 한다.

## 3. 공공데이터포털(data.go.kr) 활용신청
`DATA_GO_KR_KEY` 하나로 여러 서비스를 쓰지만 **서비스마다 활용신청**이 필요하다. 미신청이면 `SERVICE_KEY_IS_NOT_REGISTERED`(403).

| 서비스 | 용도 |
|---|---|
| 기상청_기상특보 조회서비스 (`WthrWrnInfoService`) | 기상 수요 신호 |

마이페이지 → 데이터활용 → Open API → 활용신청 현황에서 **승인** 확인. 승인 후 반영까지 1~2시간.

## 4. 통계누리(stat.molit.go.kr)
`CAR_NEWREG_FORM_ID=5498`은 **자동차등록대수현황 시도별(누적)** 표다. 브리프·뉴스 도구는 "등록대수(누적) · 전월 대비 ±N대"로 표시한다.
월별 **신규등록** 대수로 바꾸려면 통계누리에서 신규등록 표의 form_id·style_num을 찾아 Secret을 바꾼다(파서는 같은 formList 형식이면 그대로 동작).
