# Modoo UI 시스템

허브와 8개 업무 도구의 화면 뼈대는 유지하되, 브랜드·아이콘·상호작용을 공통 레이어로 통일한다.

## 구성

- `icons/modoo-mark.svg`: 네이비 바탕과 오렌지–코랄 M을 사용한 기본 브랜드 마크
- `icons/modoo-*.png`: 파비콘·Apple Touch·PWA용 파생 이미지
- `shared/ui-polish.css`: 공통 간격, 표면, 그림자, 포커스, 반응형, 모션 감소 규칙
- `shared/ui-icons.js`: 도구별 선형 아이콘, 테마 아이콘, 검색 아이콘, 본문 건너뛰기 링크

## UX 원칙

1. 허브 상단에는 연간플랜·키워드·소재·뉴스만 우선 노출하고 나머지는 `더보기`에 둔다.
2. 모바일 하단 탭은 `플랜 → 키워드 → 소재 → 뉴스 → 전체` 순서로 업무 흐름을 따른다.
3. 도구별 고유 색은 상태 구분에만 사용하고, 사이드바·카드·헤더의 표면과 간격은 공통 규칙을 사용한다.
4. 아이콘은 장식용 이모지 대신 `currentColor` 선형 SVG를 사용한다.
5. 키보드 포커스, 본문 건너뛰기, 44px 이상 모바일 조작 영역, 모션 감소 설정을 유지한다.

## 변경 시 확인

- 새 페이지에는 SVG 파비콘과 `shared/ui-polish.css`, `shared/ui-icons.js`를 연결한다.
- 새로운 주요 아이콘은 `shared/ui-icons.js`에 추가해 색상·선 굵기를 통일한다.
- 콘텐츠 안의 이모지는 의미 전달에 도움이 될 때만 사용하며 앱 헤더·내비게이션에는 사용하지 않는다.
- `python -m unittest tests.test_ui_system`과 전체 HTML JavaScript 문법 검사를 통과해야 한다.
