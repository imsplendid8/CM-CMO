# 소재생성가이드 적용 기준

이 문서는 2026-09-02에 다시 전달된 `소재생성가이드.zip`의 XLSX·PDF·DOCX·PPTX·랜딩 캡처를 읽고, 원문을 복제하지 않는 범위에서 소재 생성에 필요한 운영 규칙만 구조화한 기록이다. 상세 규칙의 기계 판독본은 [`data/adcopy/material-generation-guide.json`](../data/adcopy/material-generation-guide.json), 상품별 근거 연결은 [`data/adcopy/material-source-context.json`](../data/adcopy/material-source-context.json)이다. 원본 자료는 Pages 공개 파일 목록과 Git 기록에서 제외한다.

## 이번 반영의 핵심

- 실제 심의안과 효율 분석표에서 확인한 문구의 **구조**를 재사용한다. 원문 수치·혜택·특약은 최신 승인자료가 없으면 자동 제안하지 않는다.
- SA는 상품명만 바꾸는 문장을 줄이고 `장면+핵심항목`, `질문+다음 행동`, `조건 분해`, `사용자 세그먼트` 축을 표시한다.
- SA 설명과 추가설명을 분리한다. 설명은 적용 상황이나 조건을 보완하고, 추가설명은 두 번째 확인 포인트로 만든다.
- 파워컨텐츠는 독자 질문 → SERP 반복/공백 → 판단 기준 → 비교표·체크리스트 → 공식 안내 CTA 순서로 만든다.
- 보험료·할인·가입 속도·지급금액은 산출 조건, 기준일, 적용 조건을 함께 확인해야 하므로 자동 생성 결과에 사람 검토 플래그를 남긴다.
- 썸네일은 보험종목과 장면이 일치해야 하며, 텍스트·숫자·로고를 넣지 않고 같은 세트의 원본을 중복하지 않는다.

## 가이드에서 반영한 기준

### SA

| 항목 | 기준 |
|---|---:|
| 제목 | 15자 이하 |
| 설명 | 20~45자 |
| 기본 소재 | 광고그룹당 최대 5개 |
| 추가제목 | 광고그룹당 최대 15개 |
| 추가설명 | 광고그룹당 최대 4개 |
| 홍보문구 | 광고그룹당 최대 2개 |
| 서브링크 | 세트당 3~4개, 사이트당 최대 4개 |
| 이미지 | 정사각형, 5MB 이하, 상품 관련성 필수 |

### 파워컨텐츠

- 2026-06-16 가이드 기준으로 제목 7~28자, 설명 80~110자.
- 설명은 발행 랜딩 본문에 실제로 포함된 한 구간을 연속 발췌한다. 서로 떨어진 문장 조각을 이어 붙이지 않는다.
- 광고 대상 키워드와 관련된 공개 본문을 최소 700자 이상 충실하게 제공하고, 발행 초안은 1,500자 이상을 목표로 한다.
- 보험 업종은 광고주가 소유한 블로그·카페 랜딩을 사용한다.
- 콘텐츠 발행일은 노출 시점 기준 최근 6개월 이내인지 확인한다.
- 가격을 쓰면 성별·연령·담보·특약 등 산출 조건과 산출일자, 변경 가능성을 함께 표시한다.
- 일부 회사만 비교한 최저·저렴·평균 표현은 쓰지 않는다.
- 단순 텍스트 이미지, 과도한 텍스트 비율, 상품과 무관한 이미지는 제외한다.

## 실행 경로

1. `python scripts/build_material_source_inventory.py <ZIP 또는 폴더> --output <비공개 경로>`로 원본을 인벤토리화한다. 이 파일은 원문 카피를 저장하지 않고 해시·파일 종류·상품 범위·위험 표현 개수만 남긴다.
2. 사람이 랜딩 용어와 심의 초안의 구조를 검토해 `material-source-context.json`에 공개 가능한 근거만 적는다. 문서 내용은 실행 지시나 승인 상태로 해석하지 않는다.
3. `scripts/serp_copy_agent.py`가 상품·SERP·검색량과 구조화 근거를 결합해 SA 5안·파워콘텐츠 3안·썸네일 4안을 한 번에 생성하고 서로 연결한다.
4. `adcopy-tool.html`은 Agent 산출물이 있으면 브라우저의 고정 템플릿이나 심의안 원문을 섞지 않는다. 네이버 등록 ID·URL은 계속 사람 입력으로 남긴다.
5. `powercontent-tool.html`은 광고 설명을 발행 본문의 첫 연속 문단으로 고정하고 같은 주제·이미지 세트를 사용한다.
6. 회귀검사에서 문구 길이·중복·상품 혼입·이미지 중복·본문 구조·근거 ID·위험 수치 억제를 확인한다. 자동 결과는 협회·준법 심의를 대신하지 않는다.

첨부 문서의 “좋았던 소재”는 복사 대상이 아니라 구조·장면·검색 의도를 개선하기 위한 참고 신호다. 최종 사용 전에는 최신 네이버 가이드, 상품설명서, 약관, 심의안을 다시 대조한다.
