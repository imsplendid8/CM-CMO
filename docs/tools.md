# 도구별 상세

공통: 좌측 사이드바에서 상품 선택, 상단 테마 토글. 상품 집합은 **13종 동일**(홈·주택화재·골프·암·치아·운전자·여성건강·태아·해외여행·해외장기체류·홀인원·행사배상책임·유병자 간편) — `data/products.json` 단일 마스터, CI 드리프트 가드(`scripts/check_products_sync.py`). 디자인=Clean SaaS Light + Pretendard 자체호스팅, 전 페이지 CSP + no-referrer.

## 1. 테크니컬 SEO 콘솔 — `seo-audit.html`
- **목적**: 담당 상품 현행 화면(제목·메타·OG·H·robots·분기)을 진단하고, 화면에 바로 붙일 HTML 태깅 가이드·robots.txt 제공.
- **핵심**: 상품별 우선순위 To-Do + before/after 코드, 네이버 웹마스터도구 가이드 반영, 브라우저용 Excel 산출.
- **월간 FAQ**: 선택 월·익월 시즌 이슈와 실제 SearchAd 수요를 근거로 상품별 FAQ 4개를 제안한다. 화면 문구와 동일한 FAQPage JSON-LD를 함께 복사할 수 있으며, 월간 교체 2개·수요 반영 1개·상시 유지 1개로 구성한다. 보험료·보장·면책은 상품설명서와 약관 확인을 전제로 한다.

## 2. 검색광고 키워드 추출 — `keyword-tool.html`
- **목적**: 상품 시드 × 수식어로 검색광고 키워드 대량 생성·분류·CSV.
- **데이터**: `PRODUCTS`(상품)·`MODS`(수식어)·`AGES`. `genKeywords()`가 거래/정보/브랜드/담보/AI 인텐트로 분류하고 플랫폼(네이버/구글)·매치타입 추천.
- **네이버 검색량**: 주간 SearchAd 수집 결과(`data/volume.json`)의 PC·모바일 월간 검색량과 경쟁도를 기본 병합한다. 필요하면 팀 공유 프록시(`/searchad/keywordstool`)로 즉시 갱신하며 브라우저에 API 키를 저장하지 않는다.
- **월간 신규·급상승**: `data/volume-history.json`의 월 스냅샷을 비교한다. 전월 0·당월 100 이상이면 신규, 전월 10 이상·50회 이상 증가·50% 이상 상승이면 급상승 후보로 표시한다. 후보 생성까지만 자동화하고 채택은 사람이 검토한다.
- **네이버 대량등록 파일**: `⬇ 네이버 대량등록` 버튼 → 캠페인=상품 / 광고그룹=상품×인텐트(거래·브랜드·담보·정보), 네이버 대상만(구글·AI 제외). 컬럼: 캠페인유형·캠페인·광고그룹·키워드·입찰가·연결URL(PC/모바일)·인텐트·월검색량·경쟁도.

## 3. 카테고리 뉴스 모니터링 — `news-tool.html`
- **목적**: 상품과 같은 카테고리 기준 경쟁·시장 뉴스 요약·시사점.
- **데이터**: `NEWSMON[상품키] = { summary, insight, items:[{t,src,date,url,gist}], live? }`. 헤드라인·링크는 공개 뉴스, 요약·시사점은 자체 분석.
- **카드 자동 반영**: 카테고리 카드 헤드라인은 **클리핑 아카이브(`data/clips/`) 최신 일자**를 자동 반영(요약·시사점은 정적 유지). 스탬프 3단계(실시간/자동수집/스냅샷).
- **실시간 갱신(선택)**: 🔄 버튼 → 팀 공유 프록시(`/naver/v1/search/news.json`)로 즉석 조회(키 입력 없음·저장 안 됨).

## 4. 검색결과 주간 아카이브 — `serp-tool.html`
- **목적**: 상품 대표키워드(PC) 네이버 검색결과를 매주 스크린샷으로 아카이빙 → 전/후 비교로 변화 추적.
- **자동 캡쳐(정식 경로)**: `serp-capture.yml`(주간)의 Playwright가 네이버 SERP를 캡쳐해 `serp/`에 커밋 → 툴이 `serp/manifest.json`으로 표시. (샌드박스 세션에서만 외부망 차단이라 안 될 뿐, Actions 오픈 네트워크에선 성공. SERP는 공개 검색결과라 PII 없음.)
- **경쟁사 브랜드검색 갤러리**: 사이드바 `🏷 경쟁사 브랜드검색` — 삼성·KB·현대·DB 다이렉트×상품을 PC·모바일로 매주 자동 캡쳐(`serp/brand/`, 매니페스트). **검색광고 소재 툴에도 같은 탭**으로 통합.
- **개인 업로드(보조)**: `＋ 개인 스크린샷 올리기` → `localStorage(mf_serp)`에 날짜별 저장(전송 0·팀 공유 아님). ⬇백업/⬆복원 JSON. (팀 공유 자동 캡쳐는 배포 주소에서 자동 표시 — `file://`로 열면 미표시 안내 배너.)
- **분석**: `SERPINTEL[상품키] = { comps:[{who,area,hook}], ours, change }` — 경쟁사 소구포인트·우리 대응·변화. 한화 상위노출 갭 표시(주택화재·골프·해외여행).
- **전/후 시각 diff**: 두 주차를 고르고 **🔍 변화 감지** → canvas 픽셀 비교(pixelmatch 방식)로 바뀐 영역을 붉게 하이라이트 + 변화율%·민감도 슬라이더·길이변화 경고(외부 라이브러리 0).

## 5. 연간 시즈널 이슈 캘린더 — `seasonal-tool.html`
- **목적**: 상품별 계절 이슈·키워드·**선제 대응 시점**(예: 주택화재 6~8월 장마 → 누수·침수·풍수재).
- **데이터**: `SEASONAL[상품키] = [{ m:[월], tag, why, kws:[], act }]`. 캐노니컬 소스는 `data/seasonal.json`(데일리 브리핑도 소비).
- **뷰**: 월을 직접 선택하고 선택 월 실행안과 익월 준비안을 나란히 본다. 상품×월 히트맵, 시즌별 카드, 키워드 칩, 데이터랩 실측 12개월 스파크라인을 제공한다.
- **검색량 근거**: 시즌 키워드와 `data/volume.json`을 매칭해 실제 SearchAd PC+모바일 월검색량을 표시한다. SearchAd 값은 달력월의 확정 유입이 아니라 API가 제공하는 추정 월간 검색량이다.

## 6. 검색광고 소재 — `adcopy-tool.html`
- **목적**: 네이버 파워링크 롤링 T&D 후보를 상품별로 생성하고 심의안 초안·내부 검토용 파일로 정리한다. 광고주센터 공식 템플릿 열 매핑은 제공하지 않는다.
- **플랜 연동**: 연간플랜과 같은 선택 월을 공유하고, 선택 월과 익월에 해당하는 `data/seasonal.json` 이슈만 소재에 사용한다. 예를 들어 8월 소재에는 해당 기간 근거가 없는 신년 이슈를 섞지 않는다.
- **상품별 소재**: 광고제목·추가제목·설명·홍보문구·서브링크·이미지형 서브링크를 실제 심의안 순서로 표시한다. 개별 문구 복사와 수기 검수 입력창은 없애고, 보종·운영매체·심의번호·노출예시·썸네일 영역을 포함한 **Excel 심의안 초안**으로 내보낸다. 운전자보험은 제공된 2026-07-30 실제 심의안의 표현 구조를 기준으로 후보를 구성한다.
- **근거 패널**: **실측 월검색량**(`data/volume.json`, 검색광고 API 주간) 상위 키워드+경쟁도 + 뉴스 동향 + 경쟁사 SERP 소구 + 우리 대응 각도.
- **날씨 대응 소구**: 기상특보(`data/signals.json`, 기상청 API)별 제목·설명 — 주택화재(건조·호우·태풍·폭염·한파·대설) / 운전자(한파·대설·강풍). **특보 발효 시 '지금 발효중' 자동 강조**. 매핑은 `scripts/fetch_signals.py`(건조→발화·산불, 호우/태풍→누수·침수·풍수재, 한파/대설→동파·난방화재·빙판, 폭염→전기과부하 화재).
- **주차별 소재 캘린더**(탭): 선택 월 첫 주부터 6주 × 집중 상품·이슈 + 추천 제목/설명 + 경쟁사 광고소재 참고. 같은 달이면 주마다 다른 이슈 순환.
- **경쟁사 브랜드검색**(탭): serp/brand 매니페스트 이식(삼성·KB·현대·DB, PC·모바일, 라이트박스).
- 규격: 제목·추가제목 ≤15 / 설명 20~45 / 추가설명 ≤45(광고그룹당 최대 4) / 홍보문구 ≤14(최대 2) / 서브링크명 ≤6(소재당 3~4·사이트당 최대 4). 세부 출처와 적용 원칙은 [네이버 SA·파워컨텐츠 소재 검수 기준](naver-ad-material-guide.md)을 따른다. **광고심의 검수 전 초안**.

## 7. 파워콘텐츠 소재 — `powercontent-tool.html`
- **목적**: SearchAd 키워드 수요에서 블로그 콘텐츠 소재와 본문 초안, 파워콘텐츠 광고 문안을 함께 기획한다.
- **검색 근거**: `data/volume.json`의 SearchAd 월검색량과 `data/adcopy/powercontent-title-opportunities.json`의 검색 제목 근거를 사용한다.
- **범위 가드**: 상품명·대표키워드·담보 토큰과 일치하지 않거나 `자동차보험`, `공개관측` 등 담당 범위 밖 표현이 들어간 후보는 화면에서 제외한다.
- **구성**: 대표·연관·본문 보조·시즌 키워드, 콘텐츠 소재 3안, 선택 소재의 검색 의도와 독자·각도, 도입부, 본문 5개 섹션, FAQ 4개, CTA, 대표 이미지 브리프와 연결 광고 문안을 함께 표시한다.
- **제안 범위**: 대표·연관·본문 보조·시즌 키워드, 콘텐츠 3안, 검색 의도·독자·각도, 도입부, 본문 5개 섹션, FAQ, CTA, 대표 이미지 브리프와 광고 제목·설명 후보를 제공한다.
- **내보내기**: 선택한 콘텐츠의 키워드 전략과 전체 본문 초안을 브리프 CSV로 내보낸다. 광고 설명 후보는 도입부에 동일 문장으로 포함하며, 실제 등록 전 발행본문에 문장이 그대로 존재하는지 사람이 확인한다.

## 분석 스킬 — `.claude/skills/`
- `cm-news-analysis`: 뉴스·SERP·시즌 분석 산출물의 톤·포맷 표준(핵심요약+상세 2단계, 이슈–영향–참고 3요소, 메인 3종 강조).
- `card-news-summary`: 카드뉴스 요약.
- `humanize-korean`: `epoko77-ai/im-not-ai`의 의미 보존 원칙을 적용한 한국어 윤문. 소재·뉴스·텔레그램·이메일에 공통 적용하며 수치·날짜·상품명 보존과 변경률 30% 상한을 강제한다.
