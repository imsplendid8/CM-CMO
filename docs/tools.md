# 도구별 상세

공통: 좌측 사이드바에서 상품 선택, 상단 테마 토글. 상품 집합은 **13종 동일**(홈·주택화재·골프·암·치아·운전자·여성건강·태아·해외여행·해외장기체류·홀인원·행사배상책임·유병자 간편) — `data/products.json` 단일 마스터, CI 드리프트 가드(`scripts/check_products_sync.py`). 디자인=Clean SaaS Light + Pretendard 자체호스팅, 전 페이지 CSP + no-referrer.

## 1. 테크니컬 SEO 콘솔 — `seo-audit.html`
- **목적**: 담당 상품 현행 화면(제목·메타·OG·H·robots·분기)을 진단하고, 화면에 바로 붙일 HTML 태깅 가이드·robots.txt 제공.
- **핵심**: 상품별 우선순위 To-Do + before/after 코드, 네이버 웹마스터도구 가이드 반영, Excel/PPT 전달용 산출.

## 2. 검색광고 키워드 추출 — `keyword-tool.html`
- **목적**: 상품 시드 × 수식어로 검색광고 키워드 대량 생성·분류·CSV.
- **데이터**: `PRODUCTS`(상품)·`MODS`(수식어)·`AGES`. `genKeywords()`가 거래/정보/브랜드/담보/AI 인텐트로 분류하고 플랫폼(네이버/구글)·매치타입 추천.
- **네이버 실시간 검색량**: `livePanel`(🔌 네이버 실시간 검색량)에서 상품 선택 후 버튼 하나로 검색광고 API 월검색량·경쟁도를 프록시(`/searchad/keywordstool`) 경유로 병합(팀 공유 프록시라 키 입력 불필요, 개인 키 override 가능). 로컬 서버 폴백: `scripts/naver_local_server.py`. `docs`의 KEYWORD-API 참조.
- **네이버 대량등록 파일**: `⬇ 네이버 대량등록` 버튼 → 캠페인=상품 / 광고그룹=상품×인텐트(거래·브랜드·담보·정보), 네이버 대상만(구글·AI 제외). 컬럼: 캠페인유형·캠페인·광고그룹·키워드·입찰가·연결URL(PC/모바일)·인텐트·월검색량·경쟁도.

## 3. 카테고리 뉴스 모니터링 — `news-tool.html`
- **목적**: 상품과 같은 카테고리 기준 경쟁·시장 뉴스 요약·시사점.
- **데이터**: `NEWSMON[상품키] = { summary, insight, items:[{t,src,date,url,gist}], live? }`. 헤드라인·링크는 공개 뉴스, 요약·시사점은 자체 분석.
- **실시간 갱신(선택)**: 로컬서버 `POST /news`(네이버 개발자센터 검색 API 프록시) → 🔄 실시간 갱신.

## 4. 검색결과 주간 아카이브 — `serp-tool.html`
- **목적**: 상품 대표키워드(PC) 네이버 검색결과를 매주 스크린샷으로 아카이빙 → 전/후 비교로 변화 추적.
- **자동 캡쳐(정식 경로)**: `serp-capture.yml`(주간)의 Playwright가 네이버 SERP를 캡쳐해 `serp/`에 커밋 → 툴이 `serp/manifest.json`으로 표시. (샌드박스 세션에서만 외부망 차단이라 안 될 뿐, Actions 오픈 네트워크에선 성공. SERP는 공개 검색결과라 PII 없음.)
- **경쟁사 브랜드검색 갤러리**: 사이드바 `🏷 경쟁사 브랜드검색` — 삼성·KB·현대·DB 다이렉트×상품을 PC·모바일로 매주 자동 캡쳐(`serp/brand/`, 매니페스트). **검색광고 소재 툴에도 같은 탭**으로 통합.
- **개인 업로드(보조)**: `＋ 개인 스크린샷 올리기` → `localStorage(mf_serp)`에 날짜별 저장(전송 0·팀 공유 아님). ⬇백업/⬆복원 JSON. (팀 공유 자동 캡쳐는 배포 주소에서 자동 표시 — `file://`로 열면 미표시 안내 배너.)
- **분석**: `SERPINTEL[상품키] = { comps:[{who,area,hook}], ours, change }` — 경쟁사 소구포인트·우리 대응·변화. 한화 상위노출 갭 표시(주택화재·골프·해외여행).
- **전/후 시각 diff**: 두 주차를 고르고 **🔍 변화 감지** → canvas 픽셀 비교(pixelmatch 방식)로 바뀐 영역을 붉게 하이라이트 + 변화율%·민감도 슬라이더·길이변화 경고(외부 라이브러리 0).

## 5. 연간 시즈널 이슈 캘린더 — `seasonal-tool.html`
- **목적**: 상품별 계절 이슈·키워드·**선제 대응 시점**(예: 주택화재 6~8월 장마 → 누수·침수·풍수재).
- **데이터**: `SEASONAL[상품키] = [{ m:[월], tag, why, kws:[], act }]`. 캐노니컬 소스는 `data/seasonal.json`(데일리 브리핑도 소비).
- **뷰**: 이번 달 주목 + 다음 달 선제대응 예고, 상품×월 히트맵, 시즌별 카드, 키워드 칩(네이버 검색·데이터랩 `data/trends.json` 실측 검증).

## 6. 약관 용어 변환 — `terms-tool.html`
- **목적**: 보험 표준약관의 어려운 용어를 소비자가 이해하는 쉬운 표현으로 변환(가입화면·검색광고·상세 카피용).
- **핵심**: 표준약관 원문 → 소비자 쉬운 표현 + 용어 난이도 등급·활용 팁, 분류·검색·원클릭 복사. `.claude/skills/insurance-terms` 스킬과 짝.

## 7. 검색광고 소재 — `adcopy-tool.html`
- **목적**: 네이버 파워링크 **실제 등록 양식(롤링 T&D)** 소재를 상품별로 생성.
- **상품별 소재**: 5블록(①광고제목 ②추가제목 롤링 ③설명 롤링 ④홍보문구 ⑤서브링크 택4) — 각 글자수 자동 카운트, 규격 밖·심의금지 후보 자동 제외. 시즌·뉴스 반영분 빨강 하이라이트. **엑셀(.xls) 다운로드** + 표 복사(TSV). 홍보문구·서브링크는 상품 담보·소구 토큰 반영.
- **근거 패널**: **실측 월검색량**(`data/volume.json`, 검색광고 API 주간) 상위 키워드+경쟁도 + 뉴스 동향 + 경쟁사 SERP 소구 + 우리 대응 각도.
- **주차별 소재 캘린더**(탭): 다가오는 6주 × 집중 상품·이슈 + 추천 제목/설명 + 경쟁사 광고소재 참고. 같은 달이면 주마다 다른 이슈 순환.
- **경쟁사 브랜드검색**(탭): serp/brand 매니페스트 이식(삼성·KB·현대·DB, PC·모바일, 라이트박스).
- 규격: 제목·추가제목 ≤15 / 설명 20~45 / 홍보문구 ≤15 / 서브링크 ≤6. 조사(으로/로)·중복단어 자동 정리. **광고심의 검수 전 초안**.

## 8. 논문 아카이브 — `papers-tool.html`
- **목적**: CM 다이렉트 마케팅 참고 논문을 대시보드에서 열람(주제 필터·제목/요약 검색·원문 링크·담당자 참고).
- **데이터**: `data/papers.json`(구조화본) ← `docs/논문-아카이브.md`(정본, GitHub 렌더). 매월 1일 `papers.yml`이 네이버 학술 검색으로 신규 논문 적립 시 `scripts/papers_to_json.py`로 json도 동기화. 원문은 링크만, 요약은 공개 서지 기반.
