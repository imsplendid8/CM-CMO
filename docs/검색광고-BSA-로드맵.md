# 검색광고(SA)·브랜드검색(BSA) 솔루션 로드맵

_각 기능을 "목표·입력·출력규격·연동·제약·검증" 6요소로 정의해 하나씩 구현. 광고 문구·소재는 모두 **광고심의 검수 전제(초안)**, 데이터는 **공개·비식별**, 키는 **워커 시크릿**._

## A. 검색광고(SA) 솔루션

| # | 기능 | 상태 | 필요 입력 |
|---|---|---|---|
| A1 | 키워드 추출 → **네이버 대량등록 파일**(광고그룹핑) | ✅ 완료 | — |
| A2 | 검색광고 **문구 소재** 제작 (제목·설명 N종) | ✅ 완료 | — |
| A3 | 검색광고 **파워컨텐츠 소재** 제작 | ⬜ | 파워컨텐츠 규격(제목/본문/이미지 슬롯) |
| A4 | **소재 규격 → 딸깍 생성** (시즌캘린더·뉴스·SERP 아카이브 연동) | ⬜ | 규격 스키마 |
| A5 | **심의 규격 → 텍스트+썸네일 시안**(썸네일은 SVG 목업) | ⬜ | 심의 체크리스트 |
| A6 | 네이버 API로 **그룹별 예산 on/off·소진 현황** | ⬜ | 검색광고 **관리 API** 권한(검색 API와 별개) |

### A1 상세 (완료)
- `keyword-tool.html` → **네이버 대량등록** 버튼: 캠페인=상품 / 광고그룹=상품×인텐트(거래·브랜드·담보·정보), 네이버 대상만(구글·AI 제외).
- 컬럼: 캠페인유형·캠페인·광고그룹·키워드·입찰가(빈칸)·연결URL(PC/모바일)·인텐트·월검색량·경쟁도.
- 실제 네이버 대량관리 템플릿 컬럼을 주시면 그 규격으로 정밀 매핑 가능.

### A2 상세 (완료 · 실제 등록 양식 반영)
- `adcopy-tool.html` (✍️ 검색광고 소재): 실제 네이버 파워링크 **롤링 등록 양식 5블록**을 그대로 산출 — **① 광고제목(브랜드형) · ② 추가제목 롤링 · ③ 설명 롤링 · ④ 홍보문구 · ⑤ 서브링크(택4)**. 각 문구 **글자수 자동 카운트**, 규격 밖·심의금지 후보 자동 제외.
- **시즌·뉴스 반영분은 빨강 하이라이트** — 시즌 캘린더(가까운 이슈 순) + 뉴스/SERP 근거를 롤링 풀에 합류(예: 화재보험 → 장마 누수·겨울 난방화재·봄 건조 등).
- **엑셀(.xls) 다운로드** = 등록 양식 그대로(5블록 병렬 컬럼, 빨강=시즌·뉴스) + **표 복사(TSV)** 엑셀 바로 붙여넣기. 담당자가 받아 네이버 소재에 등록.
- 규격: 제목·추가제목 ≤15 / 설명 20~45 / 홍보문구 ≤15 / 서브링크 ≤6. 상품별 짧은 별칭(al)으로 브랜드형 제목 15자 자동 최적화(주택화재보험→"한화손보 다이렉트 화재보험" 14자), 조사(으로/로)·중복단어 자동 정리.
- 금지·주의 표현 린트(최고·최저가·1위·무조건·100%·확정·무심사 등) → 보험 광고심의 전제(초안). 심의 세부 규칙 주시면 정밀화 가능.

## B. 브랜드검색(BSA) 솔루션

| # | 기능 | 상태 | 필요 입력 |
|---|---|---|---|
| B1 | 네이버 **브랜드검색 소재 모니터링** | 🔶 부분(경쟁사 브랜드검색 캡쳐 있음) | 자사 BSA 소재 기준 |
| B2 | 검색광고 API로 **BSA on/off·계약현황 점검** | ✅ 완료 | `NAVER_SEARCHAD_*` 키(관리 API) |
| B3 | **3개월 재계약 판단**(계약 D-day·on/off 교차검증·단가 원장) | ✅ 완료 | 실제 계약 원장(`bsa_contracts.csv`) |
| B3+ | **BSA 사용 키워드 제안** 시트 | ✅ 완료 | (우선순위 판단엔 #9 검색량 연계) |

### B2·B3 상세 (완료 · **부서 전용 private 저장소 `imsplendid8/Private`**)
> 계약·단가 등 민감데이터라 공개 CM-CMO에서 분리해 부서 전용 private 저장소로 이관. 아래는 도구 설명(코드는 private에 있음).
Codex 고도화 검토분을 이식. 네이버 **검색광고 Open API**(관리 API, `/ncc/*`)를 stdlib만으로 연동:
- `searchad_client.py` — HMAC-SHA256 인증 + GET 헬퍼(캠페인/광고그룹 조회).
- `bsa_onoff_monitor.py` — BSA 캠페인·광고그룹 **on/off 자동 모니터링** + 스냅샷 대비 **변경 감지** + changelog + 카카오 '나에게' 알림. (BSA 판별은 `campaignTp`/이름 키워드, 첫 실행 `--dump-raw`로 필드 검수)
- `bsa_contract_review.py` — 계약 원장(`bsa_contracts.csv`)의 **계약종료일 D-day** + 스냅샷 on/off **교차검증** → '만료임박/계약중 꺼짐/만료 후 노출/정상' **액션** 자동 산출(3개월 재계약 vs 취소 후 재계약 판단 출발점).
- **거버넌스:** 키는 `NAVER_SEARCHAD_API_KEY/SECRET_KEY/CUSTOMER_ID` 환경변수, 실계약 원장·산출물은 `.gitignore`(샘플 `bsa_contracts_sample.csv`만 커밋).
- **한계:** BSA 계약기간은 API로 조회 불가(정액제 사전계약) → 원장은 수동 관리. on/off·예산 조회엔 **검색광고 관리 API 권한**(검색 API와 별개)이 필요.

## 제약·현실 체크
- **문구·소재**: AI는 **초안**만 — 최종은 광고심의·법무 검수.
- **썸네일**: SVG/canvas **목업** 수준(실제 광고 이미지·디자인 아님).
- **예산 on/off·계약현황**: 네이버 **검색광고 관리 API**(및 BSA 관련 권한)가 있어야 실데이터. 없으면 검색결과 노출 기반 간접 판정 + 샘플 로직.
- 단가표·심의 기준은 **사내 자료** → 프롬프트에 붙여주면 그 기준으로 구현.
