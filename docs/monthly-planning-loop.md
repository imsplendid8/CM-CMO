# 월간 플랜·FAQ·소재·키워드 연결

연간플랜에서 선택한 기준월을 SEO FAQ와 검색광고 소재가 함께 사용한다.
브라우저에는 `cm_cmo_plan_month`로 저장하며 URL의 `?month=8`처럼 기준월을 직접 전달할 수도 있다.

## 화면별 동작

- **연간플랜**: 선택월은 당월 실행, 다음 달은 익월 선제 준비로 나눠 시즌 이슈·실측 검색량·할 일을 표시한다.
- **SEO**: 상품마다 FAQ 4개를 제안한다. 당월·익월·실검색어 FAQ 3개는 월간 교체 후보이며 가입 전 확인사항 1개는 상시 유지한다. 화면 문구와 FAQ JSON-LD는 같은 데이터에서 생성한다.
- **검색광고 소재**: 선택월과 익월에 해당하는 시즌 이슈만 제목·설명 후보에 섞는다. 다른 달의 신년·휴가·명절 소재는 포함하지 않는다.
- **키워드**: 네이버 검색광고 키워드도구의 현재 검색량과 월별 스냅샷을 읽어 신규·급상승 후보를 표시한다. 후보는 현재 키워드셋에도 자동 병합된다.

## 네이버 검색량 데이터

`.github/workflows/searchad.yml`이 매주 다음 파일을 갱신한다.

- `data/volume.json`: 최신 PC·모바일 월검색량과 경쟁도
- `data/volume-history.json`: 월별 PC+모바일 합계 스냅샷, 최근 13개월

검색광고 키워드도구의 월검색량은 조회 시점의 월간 추정치다. 달력월의 확정 유입·전환 실적과는 다르므로 광고 성과 판단에는 실제 캠페인 리포트를 함께 사용한다. `data/trends.json`의 데이터랩 값은 절대 검색량이 아니라 상대 추세 지수다.

## 신규·급상승 판정

- **신규**: 전월 검색량 0회, 당월 100회 이상
- **급상승**: 전월 10회 이상, 당월 증가량 50회 이상, 증가율 50% 이상을 모두 충족
- 같은 달의 주간 실행은 해당 월 스냅샷을 최신 값으로 교체한다.
- 월 스냅샷이 1개뿐이면 후보를 만들지 않고 다음 달 데이터 수집을 기다린다.

## 월간 운영 순서

1. 연간플랜에서 기준월을 선택하고 당월·익월 이슈를 검토한다.
2. 실측 검색량이 붙은 시즌 키워드가 상품과 관련 있는지 확인한다.
3. 키워드 화면에서 신규·급상승 후보를 채택·보류·제외한다.
4. SEO FAQ 1~3번을 교체하고 상품설명서·약관 근거를 확인한다.
5. 소재 화면에서 같은 기준월의 문구만 검토하고 광고심의 전 상태로 내보낸다.

자동으로 FAQ를 게시하거나 광고를 등록하지 않는다. 모든 FAQ·소재 후보는 상품 담당자와 심의 검토를 거쳐야 한다.
