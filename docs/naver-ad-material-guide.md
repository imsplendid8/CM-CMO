# 네이버 SA·파워컨텐츠 소재 검수 기준

_최종 대조: 2026-08-25_

## 적용 원칙

- 정본은 `shared/naver-material-specs.js`다. SA와 파워컨텐츠 화면, CI 검사가 같은 값을 사용한다.
- 네이버 공개 가이드에서 확인되는 등록 원칙과 광고 관리자 등록 화면에서 확인한 글자수·등록 개수를 구분한다.
- URL과 이미지 ID는 시스템이 임의로 만들지 않는다. 담당자가 실제 랜딩·등록 자산을 확인한 뒤 입력한다.
- 모든 산출물은 내부 검토용이다. 최신 네이버 등록 화면, 상품자료·약관, 준법·광고심의를 다시 확인한다.

## 검수 규격

| 소재 | 화면 검수값 | 코드 적용 |
|---|---:|---|
| 제목 | 15자 이하 | 기본 제목·추가제목 길이 검사 |
| 설명 | 20~45자 | 기본 설명 길이 검사 |
| 추가제목 | 15자 이하·광고그룹당 최대 15개 | 후보 풀 최대 15개 |
| 추가설명 | 45자 이하·광고그룹당 최대 4개 | 후보 풀 최대 4개 |
| 홍보문구 | 14자 이하·광고그룹당 최대 2개 | 후보 풀 최대 2개 |
| 서브링크 | 이름 6자 이하·소재당 3~4개 | 상품당 최대 4개, 소재별 3~4개·중복 검사 |

파워컨텐츠는 파워링크 확장소재와 다른 상품이다. 제목 7~28자, 설명 80~110자, 연결 URL, 이미지, 업체명, 콘텐츠 발행일로 소재를 등록한다. 설명은 블로그·카페 랜딩페이지의 **연속된 문장**에서 발췌해야 하며 부분 발췌는 허용되지 않는다. 기획 단계에서는 80~110자 도입부를 제안할 수 있지만, 실제 등록에는 그 문장을 발행본문에 그대로 포함하고 존재 여부를 확인해야 한다.

## 파워컨텐츠 콘텐츠 기획 흐름

`powercontent-tool.html`은 다음 순서를 지킨다.

1. SearchAd 검색량에서 대표·연관·본문 보조·시즌 키워드를 고른다.
2. 내부 제목 검토 큐와 상품 범위 가드로 7~28자 콘텐츠 소재 3안을 만든다.
3. 선택안의 검색 의도·타깃 독자·콘텐츠 각도와 도입부, 본문 5개 섹션, FAQ, CTA, 이미지 브리프를 제안한다.
4. 도입부는 대표 키워드를 포함한 80~110자 광고 설명 후보로도 만들고 본문 초안에 동일 문장으로 포함한다.
5. 승인된 `power_content` claim이 없으면 세부 보장·금액을 단정하지 않은 일반 정보 초안만 제공한다.
6. 실제 발행 시 광고 설명 후보 문장을 그대로 포함하고, 등록 전 랜딩 원문·대표 이미지·상품자료·약관·준법·광고심의를 사람이 확인한다.

## 공개 가이드에서 확인한 운영 조건

- [추가제목 등록기준](https://ads.naver.com/adguide/1221): 파워링크 제목 기준을 따른다.
- [홍보문구 등록기준](https://ads.naver.com/adguide/1222): 파워링크 설명문구 기준을 따른다.
- [서브링크 등록기준](https://ads.naver.com/adguide/1223): 사이트당 최대 4개이며 서브링크명과 실제 URL이 일치해야 한다.
- [계산 등록기준](https://ads.naver.com/adguide/1226): 금융·보험 업종에서 조건별 가격 시뮬레이션 기능이 있는 URL만 연결한다.
- [확장소재 목록](https://ads.naver.com/adguide?categorySeq=160): 파워링크 이미지와 이미지형 서브링크는 실제 등록 자산을 사용한다.
- [파워컨텐츠 소재 만들기](https://ads.naver.com/help/faq/597): 제목·설명·연결 URL·이미지·업체명·콘텐츠 발행일을 등록하며 설명은 랜딩 원문에서 연속 발췌한다.
- [파워컨텐츠 제목/설명 기준](https://ads.naver.com/adguide/1200): 제목 7~28자, 설명 80~110자 기준을 적용한다.
- [파워컨텐츠 이미지 기준](https://ads.naver.com/help/search?categoryNo=959&searchType=TAG&searchValue=%ED%8C%8C%EC%9B%8C%EC%BB%A8%ED%85%90%EC%B8%A0): BMP·JPEG·JPG, 400×400~2,000×2,000픽셀을 사용한다.
- [파워컨텐츠 실전 세팅 가이드](https://ads.naver.com/sub/insight/adtips/169): 정보성 콘텐츠와 자연스럽게 이어지는 소재를 작성하고, 설명은 본문 문장 중 광고 가이드에 맞는 표현을 선택한다.

## 내보내기 수동 입력 필드

- 계산 연결 URL
- 파워링크 이미지 ID
- 이미지형 서브링크 이미지 ID 1~4
- 서브링크 URL 1~4

위 값은 빈 칸으로 내보낸다. 확인되지 않은 URL·이미지 ID·할인율·보험료를 자동 생성하지 않는다.
