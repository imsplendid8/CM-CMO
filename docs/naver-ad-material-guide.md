# 네이버 SA·파워컨텐츠 소재 검수 기준

_최종 대조: 2026-08-25_

## 적용 원칙

- 정본은 `shared/naver-material-specs.js`다. SA와 파워컨텐츠 화면, CI 검사가 같은 값을 사용한다.
- 네이버 공개 가이드에서 확인되는 등록 원칙과 광고 관리자 등록 화면에서 확인한 글자수·등록 개수를 구분한다.
- URL과 이미지 ID는 시스템이 임의로 만들지 않는다. 담당자가 실제 랜딩·등록 자산을 확인한 뒤 입력한다.
- 모든 산출물은 내부 검토용이다. 최신 네이버 등록 화면, 상품자료·약관, 준법·광고심의를 다시 확인한다.

## 검수 규격

| 소재 | 화면 검수값 | 코드 적용 |
|---|---:|---|
| 제목 | 15자 이하 | 기본 제목·추가제목 길이 검사 |
| 설명 | 20~45자 | 기본 설명 길이 검사 |
| 추가제목 | 15자 이하·광고그룹당 최대 15개 | 후보 풀 최대 15개 |
| 추가설명 | 45자 이하·광고그룹당 최대 4개 | 후보 풀 최대 4개 |
| 홍보문구 | 14자 이하·광고그룹당 최대 2개 | 후보 풀 최대 2개 |
| 서브링크 | 이름 6자 이하·소재당 3~4개 | 상품당 최대 4개, 소재별 3~4개·중복 검사 |

파워컨텐츠 본문용 제목 7~28자와 설명 80~110자는 네이버 공개 등록 제한이 아니라 이 프로젝트의 **내부 편집 기준**이다.

## 공개 가이드에서 확인한 운영 조건

- [추가제목 등록기준](https://ads.naver.com/adguide/1221): 파워링크 제목 기준을 따른다.
- [홍보문구 등록기준](https://ads.naver.com/adguide/1222): 파워링크 설명문구 기준을 따른다.
- [서브링크 등록기준](https://ads.naver.com/adguide/1223): 사이트당 최대 4개이며 서브링크명과 실제 URL이 일치해야 한다.
- [계산 등록기준](https://ads.naver.com/adguide/1226): 금융·보험 업종에서 조건별 가격 시뮬레이션 기능이 있는 URL만 연결한다.
- [확장소재 목록](https://ads.naver.com/adguide?categorySeq=160): 파워링크 이미지와 이미지형 서브링크는 실제 등록 자산을 사용한다.

## 내보내기 수동 입력 필드

- 계산 연결 URL
- 파워링크 이미지 ID
- 이미지형 서브링크 이미지 ID 1~4
- 서브링크 URL 1~4

위 값은 빈 칸으로 내보낸다. 확인되지 않은 URL·이미지 ID·할인율·보험료를 자동 생성하지 않는다.
