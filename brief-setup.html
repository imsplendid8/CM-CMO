데일리 브리핑 설정 빌더
🔒 개인정보 주의 · 텔레그램 chat_id·이메일 주소는 개인 식별자입니다. 이 페이지는 서버로 아무것도 보내지 않고, 입력값은 이 브라우저에만(localStorage) 저장됩니다. 생성된 값은 GitHub Secrets(비공개)에만 붙여넣으세요 — 공개 저장소에 커밋하지 마세요. 앱 비밀번호(SMTP_PASS)는 여기 입력하지 말고 Secret에 직접 넣으세요.

1 받을 사람 (수신자)

브리핑을 받을 사람의 chat_id를 추가하세요. 이름은 알아보기 쉬우라고 이 브라우저에만 남는 메모입니다(Secrets에는 chat_id만 들어갑니다).
이름(메모·로컬 전용)chat_id (숫자)
TELEGRAM_CHAT_IDS ← 이 값을 Secret 으로 
chat_id를 입력하면 여기에 생성됩니다.
chat_id 어떻게 찾나요?
1) 텔레그램에서 브리핑 봇과 대화를 시작(/start 또는 아무 메시지)합니다.
2) 가장 쉬운 방법: 텔레그램에서 @userinfobot 에게 말을 걸면 내 Id 숫자를 알려줍니다. 그 숫자가 chat_id 입니다.
3) 봇 토큰이 있으면 브라우저에서 https://api.telegram.org/bot<토큰>/getUpdates 를 열어 "chat":{"id": ...} 값을 확인할 수도 있습니다.
※ 각 수신자는 먼저 봇과 1번 대화를 해야 봇이 메시지를 보낼 수 있습니다(텔레그램 정책).

2 발송 시간 (한국시간)

하루 중 브리핑을 보낼 시각(KST)을 정하세요. GitHub Actions는 UTC로 도니, 아래에서 cron(UTC)으로 자동 변환해 드립니다.
workflow cron (UTC) ← daily-brief.yml 의 schedule 로 
시간을 추가하면 cron 이 생성됩니다.

📧 이메일 브리프 · 매일 08:30 · 텔레그램과 별도

발신 Gmail과 받을 이메일만 넣으면 됩니다. 아래 값을 GitHub Secrets에 붙여넣기.
발신 Gmail (SMTP_USER)
이름(메모)받을 이메일
① EMAIL_TO 
받을 이메일을 입력하면 생성됩니다.
② SMTP_USER 
발신 Gmail을 입력하면 표시됩니다.
③ SMTP_PASS = Gmail 앱 비밀번호(2단계 인증 후 발급) — 여기 말고 Secret에 직접.
이 3개를 GitHub Settings → Secrets → Actions 에 넣으면 매일 08:30 자동 발송.

3 적용하기

아래 순서대로 붙여넣으면 끝. 코드는 이미 다중 수신자·시간을 지원하므로, 값만 넣으면 됩니다.
  1. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret
  2. Name = TELEGRAM_CHAT_IDS · Secret = 위 1번에서 복사한 값 → 저장 (TELEGRAM_BOT_TOKEN 도 없으면 같이 등록)
  3. 발송 시간을 바꿨다면 .github/workflows/daily-brief.yml 의 schedule: 블록을 위 2번 cron 으로 교체 후 커밋
  4. 테스트: 저장소 Actions → Daily Brief → Run workflow 로 즉시 발송해 확인
· chat_id·토큰은 절대 이 저장소에 커밋하지 않습니다 — GitHub Secrets(비공개)에만.
